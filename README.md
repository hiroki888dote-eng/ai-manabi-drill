# AIまなびドリル

スマホで使えるAI学習用の4択ドリルです。

- **AIエージェント・ストラテジスト（AICX協会）コース**：公式シラバスの6章に合わせた64問と、章ごとの要点ノート
- **AI基礎コース**：G検定・生成AIパスポートなどを目指せる52問

問題 → 選択肢から回答 → 正誤 → 解説 → 「人に教えるときのコツ」の流れで、人に説明できるレベルまで理解することを目指します。

## 使い方（iPhone）

1. Safariでこのページを開く
2. 共有ボタン →「ホーム画面に追加」

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | 見た目 |
| `js/questions.js` | AI基礎コースの問題 |
| `js/agent-questions.js` | ストラテジストコースの問題と要点ノート |
| `js/app.js` | アプリの動き |
| `sw.js` | オフラインでも開けるようにする仕組み |
| `manifest.webmanifest`, `*.png` | ホーム画面用の名前とアイコン |

※問題はこのアプリのオリジナルで、公式の問題ではありません。最新の出題範囲は各試験の公式サイトで確認してください。
